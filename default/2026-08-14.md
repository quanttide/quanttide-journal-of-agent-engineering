# DeepSeek Harness 观察

从目前小红书上看到的一些实践来看，其实有一个比较有意思的做法：有什么想法，就让它做个插件安上去。这样一来，它的可自定义性和自进化性就非常强。相比于基于 skill 的这种自进化，它的可玩性要强得多，我觉得这是最关键的一点。

我觉得官方主要是还是在宣传上有问题，现在作为技术预览版，宣传的更多是技术上的理念。

我一开始会担心，这个东西人类理解起来会不会非常不好用。但是后来发现，市场好像不是这么用的。大家把它当成了一个介于 Code Agent 和龙虾这种通用 Agent 之间的东西。它的形态是一种全新的形态，你不能够用过去的理解去对待它，它和 Code Agent 的形态还是有很大的不同的。

就是它这个形态其实非常接近于我们对于量潮云的整体设计。因为我们就想用自研的平台往里面去排列组合嘛，实际上我们也考虑包容来自市场的这种东西，包括让用户去自定义，甚至去吸收这些自定义，这都在我们的计划之中。所以，其实这个形态和我们的预期还是比较一致的。
